# 排序选票计票程序

按公开且确定的淘汰规则（即时复选 IRV）选出单一获胜者，并生成可逐轮复核的计票记录。仅使用 Go 标准库。

## 用法

```sh
go run . --input 选举.json --out 输出目录
```

输出目录中生成：

- `result.json`：汇总结果（有效/无效票数、总有效权重、逐轮得票、转移量、最终获胜者）。
- `rounds.csv`：逐轮计票记录，每轮包含仍在选候选得票、本轮未耗尽权重、累计耗尽权重、淘汰者及其权重去向（`EXHAUSTED` 表示耗尽池）。

输出按键名字典序固定排序，重复运行结果一致。

## 输入格式

```json
{
  "candidates": ["alice", "bob", "carol"],
  "ballots": [
    {"weight": 5, "ranking": ["alice"]},
    {"weight": 4, "ranking": ["bob", "carol"]},
    {"weight": 1, "ranking": []}
  ]
}
```

- `candidates`：候选标识，非空、唯一、ASCII 字符串，至少一人。
- `ballots[].weight`：正整数权重。
- `ballots[].ranking`：候选的排序，可只列部分候选；空排序为有效票，但从首轮起即耗尽。

## 校验与错误处理

- 选票重复列人、引用未知候选或权重非法：该票被排除，并在 `result.json` 的 `rejected` 中记录原始序号（从 0 开始）与原因，其余选票继续计数。
- 全局结构错误（JSON 无法解析、候选列表为空、标识为空/重复/非 ASCII）：程序以非零状态退出，不生成成功结果。

## 计票规则

1. 每轮将每张有效票的全部权重分给其排序中尚未淘汰的第一位候选；无人可投时该票记为耗尽。
2. 候选得票严格大于本轮未耗尽权重的一半即当选；若未耗尽权重为零，则结束并报告无人当选。
3. 无人当选时，每轮只淘汰得票最少的一人；最低票并列时淘汰标识按字节字典序最大者。
4. 淘汰后选票按原排序转移，不改写排序；耗尽票不计入后续多数门槛。

## 计票示例

见 `examples/election.json`（含 3 张无效票）：

- 第 1 轮：alice 5、bob 4、carol 2，未耗尽 11，无人过半；carol 得票最少被淘汰，其 2 票无后继候选，转入耗尽池。
- 第 2 轮：alice 5、bob 4，未耗尽 9，5 > 9/2，alice 当选。

运行：

```sh
go run . --input examples/election.json --out out
```
